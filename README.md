# Basic Calculator

A small, clean calculator for everyday arithmetic. Runs entirely in the browser with plain HTML, CSS, and JavaScript — no libraries, no build step.

## Features

- Add, subtract, multiply, divide
- Chained operations (each operator applies the previous one, like a pocket calculator)
- Decimal input with duplicate-decimal protection
- Clear (AC) and backspace
- Full keyboard support: digits, `+ - * /`, `Enter` for equals, `Backspace`, `Esc` to clear
- Divide-by-zero shows a clear `Error` state
- Responsive layout for desktop and mobile

## Files

- `index.html` — page structure and keypad
- `styles.css` — styling and responsive layout
- `script.js` — calculator logic (vanilla JavaScript)

## How to run

Open `index.html` in any modern browser. No installation needed.
